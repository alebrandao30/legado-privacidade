# LEGADO

O LEGADO é o sistema de gestão de conteúdo e atendimento do **Ceilândia Agora**, canal de notícias locais de Ceilândia, Distrito Federal. É operado por Alessandro Brandão, para uso próprio, e não é distribuído a outras pessoas.

Para ler os comentários dos vídeos do canal no YouTube e publicar respostas a eles, o LEGADO usa a API do YouTube, sempre com a autorização do dono do canal.
