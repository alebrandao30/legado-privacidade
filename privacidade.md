# Política de Privacidade do LEGADO

Atualizada em 16 de outubro de 2026.

## Quem somos

O LEGADO é o sistema de gestão de conteúdo e atendimento do **Ceilândia Agora**, canal de notícias locais de Ceilândia, Distrito Federal. É operado por Alessandro Brandão, para uso próprio. Não é um aplicativo oferecido ao público: a única conta que o autoriza é a do dono do canal.

## Quais dados do Google o LEGADO acessa

Com a autorização do dono do canal, o LEGADO usa a API do YouTube para:

- **ler os comentários** publicados nos vídeos do canal do Ceilândia Agora;
- **publicar respostas** a esses comentários, em nome do canal.

O LEGADO não acessa e-mails, contatos, arquivos nem qualquer outro dado da conta Google, e não lê comentários de canais de outras pessoas.

## Como os dados são usados

Os comentários são lidos apenas para que o canal possa responder ao público. Para redigir a resposta, o texto de cada comentário público é enviado a um serviço de inteligência artificial contratado pelo operador, que devolve a resposta sugerida. Esse envio serve somente para gerar a resposta daquele comentário.

O LEGADO não usa esses dados para publicidade, para criar perfis de pessoas nem para treinar modelos de inteligência artificial próprios ou generalizados.

## Compartilhamento

O LEGADO **não vende, não aluga e não repassa** dados obtidos pela API do YouTube, exceto o envio descrito acima, necessário para redigir a resposta. O conteúdo dos comentários fica registrado apenas nos arquivos do computador do operador, para manter o histórico de atendimento e evitar respostas repetidas.

## Armazenamento e segurança

A chave de acesso fornecida pelo Google fica guardada num cofre local do computador do operador e nunca é publicada. O acesso pode ser retirado a qualquer momento em <https://myaccount.google.com/permissions>.

## Uso dos serviços de API do YouTube

O LEGADO usa os Serviços de API do YouTube e segue os [Termos de Serviço dos Serviços de API do YouTube](https://www.youtube.com/t/terms) e a [Política de Privacidade do Google](https://policies.google.com/privacy). O uso e a transferência das informações recebidas das APIs do Google seguem a [Política de Dados do Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado.
